2. Deploy Web Dashboard ที่เชื่อม Google Sheets จริง

1) เปิด Apps Script เดิมจาก Lab 02 และตรวจว่า Code.gs เวอร์ชันล่าสุดมีฟังก์ชัน getDashboardData() และ doGet()
2) กด (+) → HTML ตั้งชื่อไฟล์ว่า Dashboard แล้ววางเนื้อหาจาก cloud/Dashboard.html
3) Deploy Web App เวอร์ชันใหม่ และเปิด WEB_APP_URL?view=dashboard
4) ระบบเรียก google.script.run.getDashboardData() ผ่าน HTML Service แล้วแสดง KPI และกราฟ M01/M02 จาก Google Sheets
5) เปลี่ยน Potentiometer ของ M01/M02 บน Cirkit เพื่อส่งข้อมูลใหม่ กด Refresh ที่ Dashboard และตรวจค่าเปลี่ยนแปลง
เพื่อความปลอดภัย แนะนำใช้ข้อมูลห้องเรียนที่ไม่มีข้อมูลส่วนบุคคล หากเปิด Web app ให้ Anyone หน้า Dashboard จะเป็นข้อมูลที่ผู้มีลิงก์เข้าถึงได้ จึงไม่ควรใช้ข้อมูลโรงงานจริงในรูปแบบนี้
