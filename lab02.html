2. Cloud Configuration ทีละขั้นตอน

Step 1: สร้าง Google Sheet ชื่อ SmartFactory_IIoT แล้วคัดลอก Spreadsheet ID จาก URL
Step 2: Extensions → Apps Script นำไฟล์ Code.gs ไปวาง
Step 3: Project Settings → Script Properties เพิ่ม SPREADSHEET_ID และ DEVICE_TOKEN (สตริงยาวที่สร้างเอง), กำหนด READ_TOKEN เฉพาะถ้าจะใช้ JSON API อ่านข้อมูล
Step 4: Run setup() หนึ่งครั้งเพื่อสร้างชีต telemetry และหัวตาราง พร้อมอนุญาตสิทธิ์
Step 5: Deploy → New Deployment → Web app → Execute as Me → Who has access: Anyone (เฉพาะข้อมูลทดลองไม่อ่อนไหว) แล้วคัดลอก URL /exec
Step 6: ใน Cirkit Designer ตั้งค่า CLOUD_URL และ DEVICE_TOKEN ใน Arduino Sketch สองเครื่องแยกกัน โดยใช้ token เดียวกับ Script Properties
Step 7: Run Simulation, หมุน Potentiometer จริงของ Cirkit แต่ละเครื่อง, ดู Serial HTTP response แล้วกลับไปตรวจ Sheet telemetry ว่าได้ M01 และ M02 อย่างละอย่างน้อย 3 records
Step 8: ถ้ามีการแก้ Code.gs ให้ Deploy → Manage deployments → Edit → New version เพื่ออัปเดตเวอร์ชันที่ใช้งาน
Apps Script มีข้อจำกัดด้าน quota, redirect และ CORS. ห้ามใช้ fetch() จาก HTML local โดยสันนิษฐานว่าทำ POST สำเร็จเพียงเพราะไม่มี Error. หลักฐานสำคัญคือแถวใน Google Sheets และผลรับกลับของอุปกรณ์
