ออกแบบเครื่องจักร 2 เครื่องบน Cirkit Designer

ระยะเวลา 3 ชั่วโมง · ESP32-S3 สองวงจรแยกกัน (M01 CNC, M02 Assembly) · สร้าง Sensor, Wiring และ Arduino Code

1. ทฤษฎี: Sensor → Edge Controller

ESP32-S3 อ่านค่าจากอุปกรณ์ Analog ผ่าน ADC และนับชิ้นงานผ่าน Digital GPIO, ตัดสินสถานะ RUNNING/WARNING และส่ง Telemetry ไป Cloud ตามรอบเวลา โดยไม่ใช้การจำลองเป็นหลักฐานว่าส่งจริง

2. อุปกรณ์ต่อเครื่องจักร 1 เครื่อง

อุปกรณ์จำนวนการใช้งาน
ESP32-S31อ่านและส่งข้อมูล
Potentiometer 10 kΩ2จำลอง Temperature และ Vibration
Push button1นับผลิตภัณฑ์
LED เขียว/แดง + R 220Ωอย่างละ 1แสดง RUNNING/WARNING

รวมใช้ ESP32-S3 สองชุด เพื่อให้ได้เครื่อง M01 และ M02 จริงใน Simulator (โปรเจกต์แยกหรือ Canvas ที่รองรับหลายบอร์ด)

Pin Mapping (ใช้ชุดเดียวกันทั้งสองเครื่อง)

ชิ้นส่วนGPIOการเชื่อมต่อ
Temperature Pot wiperGPIO 4 (ADC)ขา 1=3.3V, ขา 3=GND
Vibration Pot wiperGPIO 5 (ADC)ขา 1=3.3V, ขา 3=GND
Product buttonGPIO 6อีกขาไป GND, ใช้ INPUT_PULLUP
Green LED anodeGPIO 15ผ่าน R 220Ω, cathode→GND
Red LED anodeGPIO 16ผ่าน R 220Ω, cathode→GND

3. Prompt สำหรับ Cirkit AI

คัดลอก Prompt แล้ววางใน Cirkit AI เพื่อช่วยสร้างอุปกรณ์และสายไฟ (ตรวจ Pin ของบอร์ดที่เลือกก่อน Run)

Create a Cirkit Designer ESP32-S3 Smart Manufacturing simulation for Machine M01. Add two 10k potentiometers: wipers to GPIO4 and GPIO5, outer pins to 3.3V/GND. Add one pushbutton GPIO6 to GND with INPUT_PULLUP, one green LED with 220-ohm resistor on GPIO15 to GND, and one red LED with 220-ohm resistor on GPIO16 to GND. Wire common GND. Label all parts. Generate Arduino firmware that reads two ADC values as simulated temperature (20-100 C) and vibration (0-10 mm/s), counts button presses with debounce, lights red LED when temperature>85 or vibration>7, else green, connects to open CirkitWifi, and posts JSON to configurable Apps Script endpoint every 10 seconds. Provide complete wiring, code, and simulator steps. Verify simulator/library compatibility. Then duplicate for M02 using separate ESP32-S3 with MACHINE_ID="M02".

ขั้นตอนปฏิบัติ

1) สร้างโปรเจกต์ ESP32-S3 แล้วเพิ่ม Potentiometer 2 ตัว, Button, LED 2 สีและตัวต้านทาน
2) ต่อวงจรตามตาราง Pin mapping และใช้ Prompt ช่วยตรวจสาย
3) เปิด Code Tab แล้ววางไฟล์ smart_factory_esp32s3.ino ตั้ง MACHINE_ID เป็น M01
4) Run Simulation หมุน Potentiometer ทดสอบไฟแดง/เขียวและปุ่มนับผลิต ดู Serial Monitor
5) ทำชุด M02 ตั้ง MACHINE_ID=M02 และทดสอบค่าเซนเซอร์แตกต่างกัน
